Program ini menggunakan library Tkinter untuk membuat aplikasi GUI prediksi program studi. `Label` digunakan untuk menampilkan teks, `Entry` untuk memasukkan 10 nilai mata pelajaran, dan `Button` untuk membuat tombol prediksi. Perulangan `for` digunakan agar 10 kolom input dibuat secara otomatis. Fungsi `prediksi_prodi()` menampilkan hasil “Teknologi Informasi” ketika tombol diklik, sedangkan `mainloop()` menjalankan aplikasi. Hasil prediksi masih tetap dan belum dihitung berdasarkan nilai yang dimasukkan.
